# チャーシューを丸く描くと卵になる問題の原因調べ (2026-10-26)

デモ (FLUX.3 klein 蒸留版 + ramen LoRA checkpoint-3000、512²、16 step) で、チャーシューを卵のように丸く描くと卵が出るという報告。
設定はデモの server.py と同じ。gp36 GPU4 で生成。

## 結果
1. **学習データの形** (shape_prior.py): 円形度 0.8 超の成分 104 個のうち、卵/半熟卵が 70 個、チャーシューが 27 個。丸い＝卵という偏りはあるが、丸いチャーシューもある。
2. **val の 10 枚でチャーシューを円にする** (gen_round.py, panel.jpg / rows/): 元の面積の円 (約 5%) では 10/10 チャーシュー。
   輪郭 cond だけ円、領域マスクだけ円、卵の削除、global caption の変更、どれでも卵にならない。
3. **卵ぐらいの大きさの楕円** (gen_size.py, 面積 0.7 / 1.5 / 2.5%、crops_ell*.jpg): ほぼチャーシューのまま。卵っぽくなったのは ramen_0014 の 2.5% だけで、卵を消しても同じ → 形だけが原因になるのはまれ。
4. **デモで描いたマスク work/027** (右のチャーシュー): 6 seed 中 3 つが卵 (半熟卵 2、ゆで卵 1)。crops_white.jpg / crops_neigh.jpg
   | 条件 (6 seed) | 卵 |
   |---|---|
   | 描いたまま | 3/6 |
   | チャーシュー caption から "white" を消す | 3/6 (画像もほぼ同じ) |
   | チャーシュー caption を "round slice of rolled chashu ..." に | 0/6 |
   | チャーシューの下にある「卵 (whole)」の切れ端 158px をチャーシューに塗る | 0/6 |
   | 卵を全部消す | 0/6 |
   | マスクはそのまま、global caption から "a halved boiled egg, a boiled egg" を消す | 0/6 |

## 原因 (027 で確かめた分)
マスクに **卵 (whole) の小さな切れ端** (158px、トークン 1 個分未満) が残っていた。原色そのままなので、AA ではなく描いた卵をチャーシューで塗りつぶした残り。
- この切れ端があると、global caption に "a boiled egg" が入り、regional caption も付く。
- でも領域が小さすぎて、そこには卵を描けない。
- そのため、モデルは隣の丸い領域 (チャーシュー) に卵を描いてしまう。
global caption から卵を消すだけで直るので、主な原因は「global caption に、マスク上でほぼ見えない物体が書かれていること」。
丸い形はその卵の行き先を決めているだけ (形だけで卵になるのは 3 のようにまれ)。

## ついでに見つけた罠
snap_to_palette で、チャーシューと半熟卵の境界のアンチエイリアス中間色 (63,159,127) を最近傍の色に寄せると **卵 (whole)** になる。
027 では 28px だけだったが、同じ現象の種になりうる。
